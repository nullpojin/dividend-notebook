# 配当ノート (Dividend Notebook)

日本株・投資信託向けの、個人用の配当・保有銘柄管理アプリです。自分のマシン上で動く小さなローカルWebアプリとして動作します。クラウドアカウントも外部データベースも不要で、データはすべてディスク上のCSVファイルとして保存されます。

想定している使い方はシンプルです。[Tailscale](https://tailscale.com) 経由でスマートフォンから、保有資産の評価額や配当収入を確認する。データは自分のマシンの外に出ません。

## 機能

- **保有銘柄管理** — 日本株・投資信託の両方に対応。評価額・評価損益を自動計算し、投資信託については基準価額が「1万口あたり」で表示される慣習に正しく対応しています（1株あたりではありません）。
- **銘柄ごとの課税区分** — 各保有銘柄を「特定/一般口座（課税）」または「NISA（非課税）」として設定できます。同期機能の税額推定や、配当集計での課税分・NISA分の内訳表示に反映されます。
- **配当管理** — 受け取った配当を記録し、年別の棒グラフで可視化。**予想年間配当**は、各保有銘柄の直近12ヶ月分の配当実績を合算したもの（年2回配当の銘柄などを過小評価しないための計算方法です）。
- **ワンクリック同期** — 証券コードが設定されている銘柄について、[`yfinance`](https://github.com/ranaroussi/yfinance) 経由でYahoo Financeから現在値と配当履歴を取得します。APIキーやアカウント登録は不要です。
- **モバイル優先のUI** — タブ切り替え式のナビゲーション（保有銘柄／配当）で、スマートフォンでの利用を想定した設計です。
- **完全ローカル動作** — データは `data/` 配下のプレーンなCSVファイルに保存され、自分で同期しない限り外部には一切送信されません。

## アーキテクチャ

| レイヤー | 選択技術 | 理由 |
|---|---|---|
| バックエンド | Python + [FastAPI](https://fastapi.tiangolo.com/) | 単一ユーザー向けのローカルアプリなので、認証やセッション管理の複雑さが不要 |
| フロントエンド | Vanilla JS / HTML / CSS | ビルド工程なし、npm不要 — フロントエンド全体が1つの静的ファイル |
| データ保存 | CSVファイル（`data/holdings.csv`、`data/dividends.csv`） | 人が読める形式で、バックアップや直接確認がしやすく、データベース管理も不要 |
| 価格・配当データ | [`yfinance`](https://pypi.org/project/yfinance/) | 無料でAPIキー不要。日本の上場銘柄についてもそれなりのカバレッジがある |

```
DividendApp/
├── backend/
│   ├── main.py           # FastAPIアプリ本体・ルーティング
│   ├── models.py         # Pydanticのリクエスト/レスポンスモデル
│   ├── storage.py        # CSV読み書き層
│   ├── price_sync.py     # yfinanceによる価格・配当の同期処理
│   └── requirements.txt

│   └── index.html        # フロントエンド全体（HTML・CSS・JSを1ファイルに集約）
├── data/

│   └── dividends.csv      # 配当履歴データ（.gitignore対象）

└── docs/
    └── screenshots/       # README用の画像
```

## セットアップ

Python 3.9以上が必要です。

```bash
git clone <このリポジトリのURL>
cd DividendApp
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

ブラウザで `http://localhost:8000` を開いてください。`data/holdings.csv` と `data/dividends.csv` は初回起動時に自動生成されます。

同一ネットワーク上の別端末やTailscale経由でアクセスしたい場合は、デフォルトの `127.0.0.1`（同一マシンからのみ接続可）ではなく `--host 0.0.0.0` を指定してください。

## 使い方

### 保有銘柄タブ

- 「＋」ボタンで銘柄を追加：銘柄名、証券コード、保有株数、取得単価、現在値を入力します。
- 日本の投資信託を登録する場合は **「投資信託（基準価額は1万口あたりで入力）」** にチェックを入れてください。ラベルが「口数」「基準価額」に切り替わり、評価額の計算も1万で割る形（実際の基準価額の表記方法）に対応します。
- NISA口座で保有している銘柄は **「NISA（非課税）口座」** にチェックを入れてください。銘柄名の横に金色の「Fund」バッジや緑色の「NISA」バッジが表示され、一目で分かるようになります。
- 各行をタップすると編集・削除ができます。
- サマリーカードには、保有評価額の合計と評価損益が表示されます。

### 配当タブ

- 「＋」ボタンで配当の受取を記録します（銘柄名・税引後の受取金額・受取日）。
- 一番上の数値は**予想年間配当**です。現在保有している各銘柄について、直近12ヶ月分の配当実績を合算したもの — あくまで直近の実績に基づく大まかな見込みであり、保証された金額ではありません。課税口座とNISA口座の両方から配当がある場合は、その内訳も下に表示されます。
- その下に、今年実際に受け取った金額（該当する場合は課税分・NISA分の内訳も）、年別の棒グラフ、配当記録の一覧が続きます。

### 同期ボタン

ヘッダーの更新アイコンをタップすると、証券コードが設定されているすべての銘柄について最新データを取得します。

- **現在値**：`yfinance` 経由の最新の株価。
- **配当**：`yfinance` から取得した過去の1株あたり配当実績をもとに、課税口座の銘柄には日本の上場株式の標準的な源泉徴収税率（20.315%）を、NISA口座に設定した銘柄には0%を適用して、税引後の推定受取額を算出します。課税口座については、標準税率を前提とした概算であり、特殊な課税状況には対応していません。
- 証券コードが未設定の銘柄（投資信託など、取引所で売買されていないもの）は同期の対象外として静かにスキップされます。日本の投資信託の基準価額・分配金データを網羅する無料で信頼できるAPIが存在しないため、これらは引き続き手入力が必要です。

## オプション：Tailscaleによるリモートアクセス

このアプリはローカルサーバーとして動作するため、[Tailscale](https://tailscale.com) を使うと、ポート開放や固定IPなしで、スマートフォンなど他の端末から安全にアクセスできます。

1. アクセス元の端末とホストマシンの両方にTailscaleをインストールし、同じアカウントでサインインします。
2. サーバーを `--host 0.0.0.0` で起動します（上記セットアップ参照）。
3. `tailscale status` でホストマシンのTailscale IPを確認し、他の端末から `http://<tailscaleのIP>:8000` にアクセスします。

## オプション：ログイン時の自動起動（macOS）

`ops/com.dividendapp.server.plist` は、ログイン時にサーバーを自動起動し、クラッシュ時には自動再起動する `launchd` のLaunchAgent設定です。中身のパスを自分のユーザー名・インストール先に合わせて書き換えたうえで、以下を実行してください。

```bash
cp ops/com.dividendapp.server.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.dividendapp.server.plist
launchctl enable gui/$(id -u)/com.dividendapp.server
```

停止する場合：`launchctl bootout gui/$(id -u)/com.dividendapp.server`

## データモデル

**`data/holdings.csv`**

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | 文字列 | UUID（自動生成） |
| `code` | 文字列 | 証券コード（例：`7203`）。投資信託など取引所非上場の銘柄は空欄 |
| `name` | 文字列 | 表示名 |
| `shares` | 数値 | 保有株数（投資信託の場合は口数） |
| `costPrice` | 数値 | 取得単価（`isFund` が true の場合は1万口あたりの単価） |
| `currentPrice` | 数値 | 現在値（`isFund` が true の場合は1万口あたりの単価） |
| `isFund` | 真偽値 | 投資信託の場合 `true`（評価額の計算方法が変わる） |
| `taxStatus` | 文字列 | `"taxable"`（課税口座）または `"nisa"`。同期機能の税額推定と、配当集計の課税分・NISA分の内訳表示に影響する |

**`data/dividends.csv`**

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | 文字列 | UUID（自動生成） |
| `name` | 文字列 | 保有銘柄と名前で照合（証券コードではない） |
| `amount` | 数値 | 税引後の受取金額 |
| `date` | 文字列 | ISO形式の日付（`YYYY-MM-DD`） |

## 既知の制限事項

- **単一ユーザー・認証なし** — Tailscaleなどの閉域ネットワーク内での利用を前提としています。ログイン機構はなく、サーバーにアクセスできる人は誰でも操作できます。
- **課税口座の配当税額はあくまで概算** — 課税口座に設定した銘柄の自動同期配当は、標準的な源泉徴収税率20.315%を前提としており、特殊な課税状況には対応していません。
- **投資信託は手入力のみ対応** — `yfinance` が上場株式・ETFをカバーしているのに対し、日本の投資信託の基準価額・分配金を網羅する無料で信頼できるAPIは存在しません。
- **`yfinance` は非公式API** — 公式に文書化された安定したAPIではなくYahoo Financeのスクレイピングに依存しているため、Yahoo側の仕様変更により動作しなくなる可能性があります。
